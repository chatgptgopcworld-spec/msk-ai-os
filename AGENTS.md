# MSK AI OS: pointer for AI agents

This is an Obsidian vault (the user's second brain). Its rules are in plain markdown and apply
to every AI tool. Before doing anything:

0. Read `AIOS/msk-me.md` (who the user is, how to work with them).
1. Read `AIOS/msk-vault-map.md` (rules, layout, conventions, projects).
2. Read `AIOS/msk-skill-map.md`, then open and follow the skill file for the task (`AIOS/skills/`).
3. Read `wiki/hot.md`, then `wiki/brain-index.md` and the last 5 entries of `wiki/brain-log.md`.

Never edit `raw/`. Never mix projects: inside `Projects/<Name>/`, that folder's `CLAUDE.md` is its
rulebook (the name is historical; it applies to every tool). Don't add rules to this file.
