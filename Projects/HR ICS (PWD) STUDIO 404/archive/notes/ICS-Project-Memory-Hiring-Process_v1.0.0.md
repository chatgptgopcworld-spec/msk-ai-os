Institute name must be written exactly "ICS [PWD] Studio 404" (never "ICSPWD"). Office is in Faisalabad. Registered label wording requested by owner: "Registered by Government of Pakistan" (owner's own claim). PSEB registration QR is shown beside it.

Flow: Google Form (CV upload inside form) -> Sheet auto-scores (Shortlist >=70 / Maybe 50-69 / Reject <50) -> one-click wa.me WhatsApp messages (Shortlist/Maybe/Reject) sent by the owner. Sheet has summary (total, counts, new today) + All/Shortlist/Maybe/Reject filter; All always available.

Owner decisions: no email, no position question, no salary question, no "why this job", no pick&drop option, no office location in intro. Pay is fixed: 1 month unpaid internship then Rs 25,000, candidate must agree. Double-job willingness = auto Reject; currently has another job = Maybe. Asks about prior IT-firm job. CV/portfolio upload accepts any file type.
