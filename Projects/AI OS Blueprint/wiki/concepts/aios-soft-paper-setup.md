# Soft Paper theme setup

**Definition:** Nick Milo's Obsidian theme and his recommended Style Settings, for a calm, paper-like workspace.

## Install
1. Settings → Appearance → Themes → Manage → search "Soft Paper" → use.
2. Community plugins → turn on → Browse → "Style Settings" → install, enable.
3. Settings → Style Settings → Soft Paper. Optional: Settings → Interface → turn off "open settings in new window" (Obsidian 1.13+) to get the see-through panel.
(see [[src-2026-10-22-nm-soft-paper-theme]])

## His settings
| Setting | His choice | Why |
|---|---|---|
| Condensed Bases rows | On | ~33% more rows visible |
| File explorer | Condensed (not extra-condensed) | more notes at a glance, still readable |
| Sidebar panes, in-note properties | Condensed | properties don't push the text down |
| Condensed body text | Off | readability first |
| Condensed settings | On | less wasted space |
| Hide "Add property" button | On | he dislikes it |
| Hide scroll bars | Off now | AI briefs vary in length; scroll bar shows progress |
| Status bar colour | Optional blue | cosmetic |
| Rainbow-coloured folders | Optional (11 colours vs default 5 ACE hues) | taste |
| Mode | Light by default; dark on planes for privacy | |
(see [[src-2026-10-22-nm-soft-paper-theme]])
