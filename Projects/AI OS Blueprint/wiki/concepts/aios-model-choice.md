# Choosing a model

**Definition:** Nick Milo's rule of thumb for which Claude model to use in Cowork.

## What the sources say
- **Sonnet** (middle) by default: good for most tasks and lets you use your plan longer (see [[src-2026-10-22-nm-obsidian-cowork-life]]).
- **Opus** (top) for meaty work: complex synthesis, deep research, quality-critical outputs; uses allowance faster (see [[src-2026-10-22-nm-cowork-80]]).
- **Haiku** (smallest) only for very light jobs such as summarising clipped web articles; otherwise you end up double-checking it (see [[src-2026-10-22-nm-obsidian-cowork-life]]).

## Synthesis
Model names change; the durable rule is "default to the mid-tier, escalate for synthesis, use the smallest only for mechanical work". It belongs in a vault map or me.md working-preferences section rather than in any one tool.
