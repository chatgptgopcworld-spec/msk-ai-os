# Obsidian basics: markdown, settings, hotkeys

**Definition:** the minimum Obsidian skills Nick Milo teaches beginners. Recorded on an older Obsidian version; menu names may differ now.

## Six markdown keys (in his order of importance)
| # | Key | Type it as | What it's for |
|---|---|---|---|
| 1 | Link | `[[Note name]]` | Strong, direct relationship between ideas |
| 2 | Tag | `#concept` | Weak, loose grouping (e.g. `#people`, `#concept`, `#movie`) |
| 3 | Italic | `*text*` | Emphasis |
| 4 | Bold | `**text**` | Draw the eye to key nouns |
| 5 | List | `- ` (or `1. `) | Bullets / numbered steps |
| 6 | Heading | `# ` to `###### ` | Title (H1) and subheads (he likes H3 for "Related") |
(see [[src-2026-10-22-nm-obsidian-masterclass]])

## Settings he changes
1. Editor: spellcheck on (optional).
2. Core plugins on: tag pane, page preview, starred notes (now **Bookmarks**).
3. Files: deleted files → system trash.
4. Files: **automatically update internal links: ON**, which he calls the single most important setting.
5. Appearance: light/dark mode; community themes optional.
(see [[src-2026-10-22-nm-obsidian-masterclass]])

## Eight hotkeys (Mac shown; on Windows Ctrl = Cmd, Alt = Option)
| Action | Mac | Windows |
|---|---|---|
| Open link while editing | Cmd+click | Ctrl+click |
| Toggle edit/reading view | Cmd+E | Ctrl+E |
| Quick switcher (jump to note) | Cmd+O | Ctrl+O |
| Search all notes | Cmd+Shift+F | Ctrl+Shift+F |
| Back / forward | Cmd+Option+← / → | Ctrl+Alt+← / → |
| New note | Cmd+N | Ctrl+N |
| Open note in a new pane | Cmd+click in file list | Ctrl+click |
(see [[src-2026-10-22-nm-obsidian-masterclass]])
