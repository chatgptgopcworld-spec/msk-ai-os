# Vault map

**Definition:** the master table of contents and operating manual for the Ideaverse. Answers "what is my Ideaverse and how should AI move through it?"

## What the sources say
- Tells AI the folder and file paths, what lives in each area and why (Atlas, Calendar, Efforts and their key subareas) (see [[src-2026-10-22-nm-3-file-ai-system]]).
- Also a **manual for creating notes**: note types, where each goes, file naming, how AI-made notes are created and marked (see [[src-2026-10-22-nm-3-file-ai-system]]).
- Covers how to interact with *other* Ideaverses (team, family) while keeping personal notes private (see [[src-2026-10-22-nm-3-file-ai-system]]).
- Kept separate from me.md so identity isn't rewritten every time a project or structure changes; the vault map changes more often (see [[src-2026-10-22-nm-3-file-ai-system]]).
- Without it, AI facing 17,000 notes samples a few and pretends it read everything; with it, AI loads only the relevant files (see [[src-2026-10-22-nm-obsidian-cowork-life]]).
- Template: [[aios-kit-vault-map]].
