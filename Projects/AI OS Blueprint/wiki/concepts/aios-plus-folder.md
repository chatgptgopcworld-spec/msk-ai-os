# The "+" (plus) folder

**Definition:** a single landing folder for new, unsorted things, used both in the file system and in the Obsidian vault.

## What the sources say
- File system: a `+` folder in your synced storage holding one single-source **downloads** folder (every browser saves there) and one **screenshots** folder (see [[src-2026-10-22-nm-big-clean]]).
- Keep them tidy with a light rule set: delete only large files (over 10 MB) after a size sort; at year end sweep everything into a year folder named with the count, e.g. "2025 screenshots (1,465)" (see [[src-2026-10-22-nm-big-clean]]).
- Vault: a `+` folder for new notes; process it in batches (path search → copy results as links → move groups → open only the notes worth thinking about) (see [[src-2026-10-22-nm-big-clean]]).
