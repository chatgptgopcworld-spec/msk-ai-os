# Claude Cowork (as shown in the videos)

**What:** the mode of the Claude desktop app (between Chat and Code, in the videos) that works directly on a folder you choose. Layer 3 in the AI OS: useful today, replaceable tomorrow.

## From the sources
- Choose a folder, allow (or always allow) access; Claude can then read, edit, move, rename and create files there (see [[src-2026-10-22-nm-cowork-80]]).
- Watch its steps and progress list; stop and re-prompt if it drifts (see [[src-2026-10-22-nm-cowork-80]]).
- Connectors link other apps (Gmail, calendar, ClickUp in his daily brief) (see [[src-2026-10-22-nm-obsidian-cowork-life]]).
- Skills can be created from a finished workflow and scheduled as recurring tasks (see [[src-2026-10-22-nm-cowork-80]]).
- Reads `CLAUDE.md` at the root of the chosen folder at session start; he keeps that file to a pointer to `me.md` (see [[src-2026-10-22-nm-obsidian-cowork-life]]).

## Note
Product details as shown in the videos (2026); the app has since folded Cowork's abilities into Claude itself, so menus and names may differ now.
