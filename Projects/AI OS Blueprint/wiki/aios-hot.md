## The system in brief
- **Foundation:** [[aios-linking-your-thinking]]: write your own ideas as notes and link them; notes gain value each time you revisit them. "Make notes, don't just take them." Tool skills in [[aios-obsidian-basics]] (links strong, tags weak; key setting: auto-update internal links).
- **Principle:** [[aios-file-over-ai]]: own your knowledge, instructions and skills as plain files; rent the AI tool.
- **Three layers** ([[aios-three-layers]]): Ideaverse in [[aios-ace-framework]] folders (Atlas, Calendar, Efforts, plus `+`) → maps and manuals in an `AIOS` folder → swappable tools ([[aios-claude-cowork]] today).
- **Three core files:** [[aios-me-md]] (who I am, how to work with me), [[aios-vault-map]] (what's where, how to create notes), [[aios-skill-map]] (every skill and when to use it). `CLAUDE.md` only points to `me.md`.
- **Skills are markdown files** kept in the vault ([[aios-skills-as-files]]), grouped into [[aios-skill-systems]]: Daily Trident, Sherpa, Weekly Review, Rock Tumbler, Chronicler, Janitor, Courier, Auto Builder.
- **Each session** starts with a loading prompt ([[aios-session-start-prompt]]). **Hygiene:** AI output separated and marked, personal areas excluded ([[aios-ai-content-hygiene]]). Mid-tier model by default ([[aios-model-choice]]).
- **Groundwork:** [[aios-big-clean]], [[aios-plus-folder]]. Optional look: [[aios-soft-paper-setup]].
