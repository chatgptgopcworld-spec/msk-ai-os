# Video 3: "The 3-File AI System That Works With ANY MODEL"

**What it is:** [[nick-milo]] lays out his **AI OS**: a model-agnostic system built on a few plain-text files you own. Record: `raw/videos/2026-10-22-nm-3-file-ai-system.md`. This is the core design video.

## Key takeaways
1. **File over AI.** Obsidian's "file over app" idea extended: your AI workflows, preferences and skills must live in your own files, so a tool shutting down, an API breaking or a model being retired costs you nothing ([[aios-file-over-ai]]).
2. **Three layers** ([[aios-three-layers]]): (1) the Ideaverse, your notes in ACE folders; (2) maps and manuals, the connective tissue that makes the Ideaverse navigable by AI; (3) tools (Obsidian, Claude Cowork, NotebookLM, Claude Code, Gemini...), the most replaceable layer.
3. A huge vault without maps wastes tokens and time; with maps, AI picks the relevant files and skips the rest. Maps of content serve humans and AI the same way ([[aios-maps-of-content]]).
4. **The three core files** live in an `AIOS` folder (beside Atlas, Calendar, Efforts):
   - `me.md`: portable identity, 50-80 lines: who I am, how I think, how to work with me. Changes rarely ([[aios-me-md]]).
   - **Vault map**: master table of contents and manual for the Ideaverse: what's in each folder, note types, naming, where AI should create notes, how to deal with other (team/family) Ideaverses. Changes more often ([[aios-vault-map]]).
   - **Skill map**: index of skills; each skill is just a markdown process file kept in an AIOS skills folder ([[aios-skill-map]], [[aios-skills-as-files]]).
5. The tool-specific file (`CLAUDE.md`) contains only one instruction: go read `me.md`.

## Details worth keeping
- me.md sections he shows: summary statement, first principles, mantras, hypothesis on meaning, values and virtues, how I think, key frameworks, intellectual lineage, recurring concepts, references, life reflections; then working preferences (first name, casual, collaborator not tool, skip filler phrases) and file paths to the other maps.
- Start with one or two skills (e.g. daily-note structure, summarising). Every few weeks, garden me.md and the vault map: still accurate? bloated?
- Privacy: using frontier tools means trusting layer-3 vendors; keep journals and other very personal areas outside AI's reach if you prefer, back up, and **mark AI-generated content** (emoji, tag or folder). A portable system can move to local models when they're good enough ([[aios-ai-content-hygiene]]).
