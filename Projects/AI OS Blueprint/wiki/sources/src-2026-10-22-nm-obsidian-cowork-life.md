# Video 4: "How I Use Obsidian + Claude Cowork to Run My Life"

**What it is:** [[nick-milo]] shows his AI OS in daily use: Obsidian Ideaverse + AIOS translation layer + Claude Cowork, and the skill systems he runs. The most complete and most recent picture. Record: `raw/videos/2026-10-22-nm-obsidian-cowork-life.md`.

## Key takeaways
1. Same three layers as video 3; the point is that Claude could be swapped for Codex or an open model tomorrow because files, skills and core docs travel with you ([[aios-three-layers]], [[aios-file-over-ai]]).
2. Setup: Cowork pointed at a parent "knowledge" folder that contains the Ideaverse vault (17,000 notes). An `AIOS` folder inside the vault keeps all AI-made material separate so it can be isolated or cleared, keeping his own thinking clean ([[aios-ai-content-hygiene]]).
3. `CLAUDE.md` at the root of the folder Claude opens says only "go read me.md". With a single vault, put that `CLAUDE.md` in the vault root ([[aios-me-md]]).
4. Keep skills **in your own system**, not inside Claude: let AI write and review them, but save them in the AIOS skills folder and list them in the skill map ([[aios-skills-as-files]], [[aios-skill-map]]).
5. Start every session with a short loading prompt (read me.md, then the vault map and skill map, confirm, wait) fired by a text-expander hotkey, because models forget ([[aios-session-start-prompt]]).
6. Skills are grouped into **systems** ([[aios-skill-systems]]): Auto Builder, Daily Trident (daily brief + daily log), Sherpa, Weekly Review, Rock Tumbler, Chronicler (+ summarizer), Janitor, Courier.

## Details worth keeping
- Daily brief: generated at 6 am as a scheduled task from Gmail, calendar, ClickUp and the vault: weather, yesterday's work, open items, important email/logistics, travel and deadlines, book momentum, intellectual life, "what might I be forgetting", and 2-3 priorities for today. He replies to the AI inside the note using `{curly brackets}` or indented bullets, even from his phone.
- Why Claude for now: says it doesn't train on user data, 30-day server retention, and is less lock-in-hungry than others; may change.
- Models: Sonnet by default, Opus for heavy synthesis, Haiku only for simple web-clipper summaries ([[aios-model-choice]]).
- You don't need ACE or a big vault to start; begin with the notes you have.
