# Skill systems

**What this is:** the groups of skills Nick Milo runs in his AI OS, as listed in his skill map. The videos show what each does, not the skill files themselves (those are in his paid "Linking Your AI" product), so the "how it would work" notes here are descriptions, not his text.

## The systems (see [[src-2026-10-22-nm-obsidian-cowork-life]] unless noted)
| System | Skills | What it does |
|---|---|---|
| **Auto Builder** | (setup) | Builds the three core files (me.md, vault map, skill map) for a new user. |
| **Daily Trident** | daily brief, daily log | *Brief*: scheduled 6 am note from email, calendar, task tool and the vault: weather, yesterday, open items, key emails/logistics, travel and deadlines, big-project momentum, intellectual life, "what might I be forgetting", 2-3 priorities. The user answers inside the note with `{curly brackets}` or indented bullets. *Log*: scheduled through the day, an interstitial journal of what got done, which feeds the next brief. |
| **Sherpa** | | Maps a new topic of interest so you learn it faster. |
| **Weekly Review** | | An extra lens on the week to catch what slipped; only read after doing your own review, so your thinking leads. |
| **Rock Tumbler** | | Fast feedback on your work by asking open-ended questions rather than rewriting it. Built on his IDI framework (imagine, discern, integrate) and Ericsson's fast-feedback principle. |
| **Chronicler** | save verbatim, summarizer | "Save this verbatim" files a conversation into a history subfolder; the summarizer adds summary, takeaways, topics and next steps on top. Good for meetings. |
| **Janitor** | | Maintains the system so it mends itself over time (the part most demos skip). |
| **Courier** | | "Share this with the team": strips personal information, adds summaries of linked notes it can't include, and files it in the team's space. |

## One-off skills shown in video 2 (see [[src-2026-10-22-nm-cowork-80]])
- **screenshot-renamer**: categorise a folder of screenshots, rename each `YYYY-MM-DD description`, move into subfolders, write an index; scheduled monthly.
- **Holistic briefing**: "where am I, what matters, what am I missing" across active projects ranked by priority; filed into the vault (later became the daily brief).
- **Research synthesis**: common themes across a folder, where sources contradict or extend *your* frameworks, insights, curriculum outline.
- **Note beautifier**: find and insert an image into a note.
- **AI-made map of content**: surface buried notes for a project, marked AI-generated.
