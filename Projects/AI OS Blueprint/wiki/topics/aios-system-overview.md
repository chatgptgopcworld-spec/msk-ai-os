## The system
0. **Foundation:** [[aios-linking-your-thinking]]: write your own ideas as notes and link them; learn the tool with [[aios-obsidian-basics]].
1. **Principle:** [[aios-file-over-ai]]. Anything you invest in an AI tool should exist as your own file first.
2. **Architecture:** [[aios-three-layers]]: Ideaverse → maps and manuals → tools.
3. **Layer 1, the Ideaverse:** notes in [[aios-ace-framework]] folders (Atlas, Calendar, Efforts, plus `+` and `X`), linked with `[[links]]` and [[aios-maps-of-content]]. Kept clean with [[aios-big-clean]].
4. **Layer 2, the AIOS folder:**
   - [[aios-me-md]]: who I am, how to work with me (rarely changes).
   - [[aios-vault-map]]: what's where, how to move and create notes (changes with structure and priorities).
   - [[aios-skill-map]] + skills folder: every repeatable process as a markdown file ([[aios-skills-as-files]]), grouped into [[aios-skill-systems]].
   - Tool files (`CLAUDE.md`) only point to `me.md`.
5. **Layer 3, tools:** [[aios-claude-cowork]] today with a sensible [[aios-model-choice]]; Obsidian ([[aios-obsidian]]) as the reading/writing interface.
6. **Every session:** [[aios-session-start-prompt]] loads me.md → vault map → skill map.
7. **Always:** [[aios-ai-content-hygiene]]: AI output separated and marked, private areas excluded, backups, human judgement leads.
8. **Rhythm:** every few weeks garden me.md and the vault map; let scheduled skills (daily brief, daily log, monthly screenshot clean) run in the background.

## How the thinking evolved across the videos
- Personal context moved from Claude's settings (video 2) to `me.md` (videos 3-4).
- Skills moved from Claude's skill library (video 2) to the vault's skills folder (video 4).
- Theme preference moved from dark/colourful (video 6, older) to light Soft Paper (video 5).
- The ad-hoc "holistic briefing" (video 2) became the scheduled daily brief inside the Daily Trident system (video 4).
Details: Contradictions sections on [[aios-me-md]] and [[aios-skills-as-files]].

## Synthesis
The system is less about any app than about three habits: write things down as files, keep a small set of maps that tell any reader (human or AI) where things are and how to behave, and turn repeated work into written procedures. MSK AI OS already practises all three in its own LLM Wiki form; [[aios-msk-adoption-plan]] lists the specific gaps.
