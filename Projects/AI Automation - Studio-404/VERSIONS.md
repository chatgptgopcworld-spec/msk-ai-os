## Rules
- Every kind of file starts at **v1.0.0** and has its own version number.
- When a file changes it gets the next version: small change = patch (1.0.0 -> 1.0.1),
  new feature = minor (1.0.x -> 1.1.0), full redesign = major (1.x -> 2.0.0).
- The old version is never overwritten: it moves to `archive/` (same sub-folder).
- Portal design rounds are one family: round 1 mockups v1.x, round 2 v2.x, round 3 concepts v3.x
  (Nebula, the chosen design, is the highest: v3.4.0).
- To deploy or load a file, use its original name (first column). Easiest: unzip the matching
  package in `packages/`, which keeps the original names (`site/`, `chrome-extension/`).
- Screenshots with applicants' names or phone numbers are kept in `private/`, which git ignores.
