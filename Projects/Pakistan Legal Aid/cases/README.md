# Cases (private)

One folder per matter: `cases/YYYY-MM-<short-slug>/` containing
- `facts.md` — intake answers, exactly as the person stated them, with [BRACKETS] for unknowns
- `evidence.md` — exhibit table with hashes
- `mapping.md` — section → ingredient → fact para → exhibit
- `draft.md` — the complaint
- `must-confirm.md` — open items before filing
- `filing-log.md` — date filed, where, reference number, follow-ups

These files contain personal data. Keep them out of any public sync or sharing. Wiki pages link to law, never to people.
